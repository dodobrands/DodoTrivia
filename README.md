# Dodo Trivia

Викторина о Додо — вопросы про историю компании, необычные случаи и интересные факты из «Додо Книги 2».

## Играть

**https://dodobrands.github.io/DodoTrivia/**

## Что внутри

- 97 вопросов в пуле — каждая сессия случайно выбирает 15
- Перепроходи и каждый раз получай новый набор вопросов
- Варианты ответов перемешиваются при каждом показе
- Таймер 60 секунд на вопрос со stories-прогрессбаром
- Числовой обратный отсчёт на последних 15 секундах
- Звуки на правильный/неправильный ответ (Web Audio API, по умолчанию выключены)
- Подсветка правильного/неправильного ответа
- Итоговый счёт с процентом и оценкой
- Кнопка «Пройти ещё раз»
- Адаптирован под мобильные устройства
- Работает без бэкенда — один HTML-файл
