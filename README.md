# Dodo Trivia

Викторина о Додо — 15 вопросов про историю компании, необычные случаи и интересные факты.

## Играть

**https://dodobrands.github.io/DodoTrivia/**

## Что внутри

- 15 вопросов с 4 вариантами ответа
- Вопросы перемешиваются каждый раз
- Подсветка правильного/неправильного ответа
- Итоговый счёт с процентом и оценкой
- Кнопка «Пройти ещё раз»
- Работает без бэкенда — один HTML-файл
